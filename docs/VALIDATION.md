# 验证结果

硬件实现使用 Quartus Prime Lite 18.1，RTL 自检使用 ModelSim SE 10.1a。公开工程另提供 Icarus Verilog 仿真入口与持续集成配置。测试不依赖厂商加密 IP。

重新编译时，工具版本及布局结果可能使资源和裕量略有变化。完整报告在本机构建后生成，不提交含本机路径的原始报告。

## 自动检查

- TRIG 高电平恰为 240 个时钟，即 20 μs。
- 回归使用 65 ms 采样周期加速测试，另有独立实例检查默认一秒周期；回归仍使用 12 MHz 测距时钟和 30 ms 超时。
- 有效距离覆盖 2、5、9、10、19、20、39、40、79、80、99、100、123、149、150、399、400 cm。
- 无效边界覆盖 1 cm、401 cm。
- 无回波、回波持续高、开始时 ECHO 已高、异常后恢复。
- 测量中按键复位、无按键的上电复位、输出无未知值。
- 米／厘米页编码、页间数据锁存、无效显示与 LED 极性。
- 每个报警分档及边界、停鸣门控、2 kHz 周期、50% 占空比。
- 独立板载显示自检的数字序列、两个小数点和复位。

每个测试平台有 watchdog。脚本同时检查进程状态和成功标记，避免把提前退出误认为通过。

## 板上验证

已观察到：显示自检正确；测距读数正常；鸣叫节奏随距离变化；2 kHz 驱动明显改善声音。正式 POF 已写入配置 Flash，另行执行的 Verify 通过。

尚未形成多距离、温度和目标材质条件下的系统误差统计，不能将厘米数字分辨率等同于全量程 ±2 cm 的实测精度。最新音频修正版的真实断电重启观察未单独记录，Flash 写入校验不能替代该验证。

## 保留的工具提示

未隐藏 Quartus 消息。保留的常量输出提示对应数码管公共阴极／未使用小数点；Lite 的 LogicLock 提示不影响本工程。

单电源 MAX10 会提示检查功耗，3.3 V 输入会提示接口电气要求。原功耗估计属于无板级热模型、未导入实际活动数据的低置信度结果，不能作为实测功耗。外接 ECHO 使用分压；实际板卡仍应核对接口电压。
